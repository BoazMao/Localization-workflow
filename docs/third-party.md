# Third-party components

## Const-me/Whisper

Localization Workflow integrates the unmodified Const-me/Whisper Windows binaries through
its official command-line package. Const-me/Whisper is distributed under the Mozilla Public
License 2.0. Official source and releases:

- https://github.com/Const-me/Whisper
- https://github.com/Const-me/Whisper/releases

The native package is installed into application data and is not committed to this repository.
Any packaged distribution must retain the upstream license and notices and keep the component
separately identifiable.

## Whisper models

Whisper model files are downloaded separately and are not committed to this repository. The
official whisper.cpp model collection is available at:

- https://huggingface.co/ggerganov/whisper.cpp/tree/main
